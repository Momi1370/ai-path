**What it teaches.** How supervised learning works end to end, and the shape of the linear model.

**Key points**
- The training set (features and targets) goes into the learning algorithm, which outputs a function f, the model.
- A new input x goes into f, which outputs y-hat, the prediction (an estimate). y without the hat is the true target.
- For linear regression f(x) = w x + b. w and b are the parameters the algorithm must choose.
- With one input feature this is called univariate linear regression.
- To make it work you need a cost function, one of the most universal ideas in machine learning.

**Remember.** y is the real answer; y-hat is the model's guess.
