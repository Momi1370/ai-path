**What it teaches.** Why machine learning matters and what this course will do for you. Ng shows that you already use it many times a day, then promises that you will learn the ideas and also implement them in code.

**Key points**
- Everyday examples: web search ranking pages, photo tagging, voice assistants, spam filters.
- It also reaches large companies and fields such as healthcare and manufacturing, not only consumer apps.
- This course is the new version of the one that led to the founding of Coursera.

**Remember.** Machine learning is already inside tools you use daily, which is why learning the basics pays off.
