**What it teaches.** The university version of the same material, with more maths. Optional deeper reading, not needed for the weekly drills.

**Key points**
- Linear regression with the notation theta for the parameters.
- Gradient descent drawn on the cost surface, then batch and stochastic gradient descent.
- The normal equation: a closed-form way to fit a linear model in one step, derived with matrix derivative notation in a few lines instead of pages.
- Choosing the learning rate is mostly empirical: people try several values and keep one that works.

**Remember.** Gradient descent walks to the answer; the normal equation jumps there when the data is small enough.
