**What it teaches.** Linear regression with several input features, and the notation for it.

**Key points**
- Instead of one feature x, the house has size, number of bedrooms, floors and age: x1 to x4. n is the number of features.
- The model becomes f(x) = w1 x1 + w2 x2 + ... + wn xn + b, called multiple linear regression.
- Reading the numbers: b = 80 means a base price of 80 thousand dollars for a house with nothing; a weight of 0.1 on size means each extra square foot adds 0.1 thousand dollars, about 100 dollars.
- In vector form f(x) = w . x + b, where w is the list of weights and x the list of features.

**Remember.** One weight per feature, plus one bias.
