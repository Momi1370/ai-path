**What it teaches.** Logistic regression in plain statistics language: predicting a probability, then a class.

**Key points**
- Linear regression predicts a number and can go below 0 or above 1. Logistic regression fits an S-shaped curve whose output stays between 0 and 1, so it can be a probability. Example: the probability that a mouse is obese given its weight.
- For classification you compare the probability with a threshold, usually 50 percent: above it, obese; below it, not obese.
- It can use continuous predictors (weight) and discrete ones (genotype), and can show which variables are useful (astrological sign is useless).
- A difference from linear regression: the curve is not fitted with least squares but with maximum likelihood (the next StatQuest explains it).

**Remember.** Same linear ingredients as before, squeezed through an S-curve so the answer is a probability.
