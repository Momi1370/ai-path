**What it teaches.** The first model of the course: linear regression, and the vocabulary of a training set.

**Key points**
- Linear regression fits a straight line to data and is probably the most used learning algorithm in the world.
- Example: house size (input) against price (output). The training set is a table of examples.
- Notation: x is the input variable (feature), y is the output variable (target), m is the number of training examples, and (x(i), y(i)) is the i-th example, row i of the table.
- This is regression because the model can output infinitely many possible numbers.

**Remember.** Training set = examples with the right answers; x goes in, y is the target.
