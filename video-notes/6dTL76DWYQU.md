**What it teaches.** The tool used for the labs: the Jupyter Notebook.

**Key points**
- Jupyter is the default environment of most machine learning and data science practitioners.
- A notebook has text cells and code cells. Shift+Enter runs a cell.
- The optional labs need no coding from you: you open them and run the code to see how machine learning code behaves. Practice labs later ask you to write some code.

**Remember.** Run, read, change one thing, run again. That is how to learn from a notebook.
